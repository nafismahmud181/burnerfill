How it works

Three steps. You do none of them.

01 Open a signup page BurnerFill recognizes the form and creates a fresh disposable inbox for it.
02 Fields fill themselves Email, a strong password and the repeat-password field are filled in one go.
03 The code arrives It watches the inbox, fills in the code or opens the verification link, and can submit the form for you.
Features

Everything a throwaway account needs.

Each one can be switched on or off in Settings.

autofill Detects signup forms Creates an inbox and fills the email, password and repeat-password fields.
otp Catches the code Polls the inbox, fills the OTP and copies it to your clipboard in case a site blocks autofill.
links Opens verify links When a site sends a link instead of a code, BurnerFill can open it for you.
inbox Built-in inbox Read every email sent to the burner address without leaving the popup.
history History + CSV Every account you create is saved locally. Export them all whenever you need.
⌘ shortcut One-key regenerate Need a new identity? Press your shortcut to create and fill a new one.

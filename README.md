# BurnerFill website

The website for **BurnerFill**, a browser extension that fills signup forms with a disposable
email and a strong password, then fills in the verification code when it arrives.

**Live site:** https://nafismahmud181.github.io/burnerfill/
**Privacy policy:** https://nafismahmud181.github.io/burnerfill/privacy.html

The files here are generated. Don't edit them in this repo - changes are made in the
extension's source repo and published here with `tools/publish-site.js`.

Questions or problems: [open an issue](https://github.com/nafismahmud181/burnerfill/issues).
